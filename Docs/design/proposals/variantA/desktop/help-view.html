Neues Konto im Kontenplan anlegen

Um ein neues Finanzkonto anzulegen, navigieren Sie in der Hauptnavigation auf „Konten“ und betätigen Sie in der oberen Aktionsleiste den Button „Konto hinzufügen“. Wählen Sie die gewünschte Kontokategorie (Girokonto, Sparkonto, Kreditkarte oder Depot) aus dem Dropdown-Menü.

Anfangssaldo und Eröffnungsbuchung

Geben Sie das Eröffnungsdatum sowie den exakten Saldo zum Stichtag ein. FinanceManager generiert hierbei automatisch eine systemische Eröffnungsbilanzbuchung gegen das Gegenkonto #9000 Saldenvortrag Sachkonten.

info

Hinweis für fehlerfreien Saldenabgleich

Für den fehlerfreien Saldenabgleich sollte das Stichtagsdatum exakt mit dem Datum Ihres letzten offiziellen Bankauszuges übereinstimmen. Nachfolgende automatische Importe (MT940/CAMT) knüpfen nahtlos an dieses Saldenkontinuum an.
