# Automatische Updates — Fehlerbehebung

## Update-Bereich ist nicht sichtbar

**Ursache:** Der angemeldete Benutzer besitzt keine Administratorrechte oder die Update-Funktion ist im Betrieb nicht verfügbar.

**Lösung:**
1. Mit einem Administratorkonto anmelden.
2. Setup erneut öffnen.
3. Falls der Bereich weiterhin fehlt, den Betreiber der Installation kontaktieren.

## Kein bereites Update vorhanden

**Ursache:** Es wurde noch kein Update gefunden, die Prüfung ist fehlgeschlagen oder das heruntergeladene Paket wurde verworfen.

**Lösung:**
1. Im Ribbon **Jetzt prüfen** wählen.
2. Warten, bis die Prüfung abgeschlossen ist.
3. Die angezeigte Statusmeldung prüfen.
4. Bei wiederholten Fehlern später erneut prüfen oder den Betreiber einbeziehen.

## Update-Lock verhindert eine Installation

**Ursache:** Eine Installation läuft noch oder wurde nicht vollständig abgeschlossen.

**Lösung:**
1. Einige Minuten warten und die Seite aktualisieren.
2. Prüfen, ob die Anwendung oder der Dienst gerade neu startet.
3. Wenn der Lock alt genug ist, im Ribbon **Update-Lock zurücksetzen** wählen.
4. Den angezeigten Grund lesen, falls der Reset abgelehnt wird.

## Installation dauert ungewöhnlich lange

**Ursache:** Der Dienst startet langsam, ist nicht erreichbar oder die Installation benötigt eine manuelle Prüfung.

**Lösung:**
1. Einige Minuten warten.
2. Die Anwendung in einem neuen Browserfenster erneut öffnen.
3. Falls sie nicht erreichbar bleibt, den Betreiber der Installation informieren.

## Nach der Installation wird weiter die alte Version angezeigt

**Ursache:** Die neue Version wurde nicht vollständig bereitgestellt oder der Dienst hat die alte Version erneut gestartet.

**Lösung:**
1. Status im Update-Bereich aktualisieren.
2. Bei weiterhin falscher Version keine weitere Installation starten.
3. Den Betreiber der Installation informieren und die Sicherung bereithalten.
