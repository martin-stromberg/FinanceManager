# Automatische Updates — Einrichtung

## Zweck

Diese Seite beschreibt die sichtbaren Einstellungen für automatische Updates in der Setup-Oberfläche.

## Einstellungen

| Einstellung | Bedeutung |
|-------------|-----------|
| Update-Prüfung aktiv | Schaltet die regelmäßige Suche nach neuen Versionen ein oder aus. |
| Prüfzeitfenster | Legt fest, wann die automatische Prüfung laufen darf. |
| Vorabversionen berücksichtigen | Bezieht Vorabversionen in automatische und manuelle Prüfungen ein. |
| Geplante Installationszeit | Gibt an, wann ein vorbereitetes Update installiert werden soll. |
| Service-Name | Benennt den Dienst, der nach einer Installation neu gestartet wird. |

## Vorgehen

1. Setup öffnen und den Update-Bereich wählen.
2. Gewünschte Einstellungen setzen.
3. Über **Speichern** übernehmen.
4. Bei Bedarf über **Jetzt prüfen** manuell nach einer neuen Version suchen.
5. Ein vorbereitetes Update über **Update installieren** starten und die Ausfallzeit bestätigen.

## Hinweise

- Die Installation kann die Anwendung kurzzeitig nicht erreichbar machen.
- Vorabversionen sollten nur verwendet werden, wenn der Betrieb diese bewusst testen möchte.
- Der Lock-Reset ist für hängen gebliebene Installationen vorgesehen und sollte nur nach Prüfung des Serverzustands verwendet werden.
