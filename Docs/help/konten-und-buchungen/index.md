# Konten und Buchungen

Dieser Bereich bildet die Kernbuchhaltung der Anwendung ab: Konten, Sammelkonten, Buchungslisten, Exporte und Stornierungen — einschließlich der Kontierungsregeln, mit denen Bankpostings automatisch eine Postenart (Eingang, Ausgang, Zinsen, Steuer) erhalten.
