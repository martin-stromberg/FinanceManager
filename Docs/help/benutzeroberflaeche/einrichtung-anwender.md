# Benutzeroberfläche — Einrichtung

## Zweck

Die Anwendung kann vor kritischen Aktionen wie dem Löschen oder Verbuchen eine Nachfrage einblenden. Ob diese Bestätigungsdialoge erscheinen, legt eine persönliche Einstellung fest.

## Einstellungen

| Einstellung | Bedeutung |
|-------------|-----------|
| Bestätigungsdialoge anzeigen | Vor kritischen Aktionen wie Löschen oder Verbuchen nachfragen. Aktiviert (Standard): Es erscheint ein Bestätigungsdialog. Deaktiviert: Die Aktion wird ohne Nachfrage sofort ausgeführt. |

## Vorgehen

1. Öffnen Sie im Menü „Einrichtung".
2. Klappen Sie den Bereich „Profil" auf.
3. Setzen oder entfernen Sie den Haken bei „Bestätigungsdialoge anzeigen".
4. Speichern Sie über „Speichern" in der Aktionsleiste.

## Hinweise

- Die Einstellung gilt für das eigene Benutzerkonto und wirkt auf alle Bestätigungsdialoge, nicht nur auf einzelne Bereiche. Sie ist unmittelbar nach dem Speichern aktiv.
- Bei deaktivierter Einstellung werden Einträge beim Löschen sofort entfernt — ohne Möglichkeit, die Aktion über einen Dialog abzubrechen.
- Bestätigungsdialoge liegen immer oberhalb geöffneter Bereiche, sodass sie auch dann bedienbar bleiben, wenn z. B. die Anhangsliste geöffnet ist.
