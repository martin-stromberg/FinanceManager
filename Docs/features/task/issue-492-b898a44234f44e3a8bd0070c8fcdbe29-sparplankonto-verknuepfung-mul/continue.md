# Offene Rückmeldungen

Erstellt am: 2026-11-08

## UX-Rückmeldung

- [ ] Im Panel zur Sparplan↔Konto-Verknüpfung einen Info-Button ergänzen.
- [ ] Der Info-Button soll erklären, wofür diese Verknüpfung gedacht ist:
  - verknüpfte Konten liefern den tatsächlichen Plan-Saldo,
  - Konto-Inflow dient als Grundlage für Rhythmus- und Defizitanalyse,
  - Funding-Postings auf anderen Konten können als informelle Belegquelle gekennzeichnet werden,
  - ohne verknüpfte Konten bleibt die bisherige Posting-basierte Betrachtung aktiv.
- [ ] Umsetzung erst nach weiterer fachlicher Rückmeldung bzw. Freigabe.
- [ ] Bei der Kontoverknüpfung dürfen ausschließlich Konten vom Typ „Sparkonto“ auswählbar sein.
- [ ] Die Einschränkung auf Sparkonten muss durch Tests abgesichert werden.

## UX-Verfeinerung Verknüpfungsliste und Saldoanzeige

- [ ] Der Button zum Entfernen einer Kontoverknüpfung soll als Symbolbutton dargestellt werden.
- [ ] Jede verknüpfte Bankkonto-Zeile soll einen Symbolbutton zum Aufruf des Bankkontos erhalten.
- [ ] Bei mehreren Verknüpfungen sollen die Salden der Bankkonten als eigene Spalte in der Auflistung angezeigt werden.
- [ ] Bei nur einer Verknüpfung soll nur der Symbolbutton zum Bankkonto gezeigt werden.
- [ ] In den Kopfdaten des Sparplans soll bei vorhandenen Verknüpfungen die Summe der Bankkontosalden als Saldo angezeigt werden.
- [ ] Zusätzlich soll der bisherige Saldo aus den Sparplanposten als „Eigenanteil“ ausgewiesen werden.
- [ ] Ohne Verknüpfung bleibt die bisherige Saldoausgabe unverändert.
- [ ] In der Sparplanübersicht muss die Saldoanzeige denselben Regeln folgen wie in den Kopfdaten.

## Demodaten

- [ ] Demodaten um ein Bankkonto für einen Bausparvertrag erweitern.
- [ ] Demodaten um einen Sparplan „Bausparen“ erweitern.
- [ ] Das Bausparkonto mit dem Sparplan „Bausparen“ verknüpfen.
- [ ] Monatliche Buchungen vom Girokonto auf das Bausparkonto erfassen.
- [ ] Zum Jahresende Zinsbuchungen in Höhe von 1 % des jeweiligen Saldos erfassen.
- [ ] Die Zinsbuchungen sollen sowohl auf dem Girokonto als auch auf dem Bausparkonto saldenwirksam berücksichtigt werden.
- [ ] Für die monatlichen Einzahlungen auf das Bausparkonto soll ein Budget in den Demodaten hinterlegt werden.
- [ ] In den Demodaten soll ein weiterer Report erfasst werden, der die monatlichen Sparplanbuchungen zeigt.
- [ ] Bei Sparplänen mit Kontoverknüpfung muss der Report die Bankkontoposten berücksichtigen können.
- [ ] Die Reporteinstellungen sollen um eine neue Option erweitert werden, die gesetzt werden kann, wenn Sparpläne ausgegeben werden sollen.
- [ ] Über diese Option soll der Anwender die Postenquelle für die ausgegebenen Sparpläne wählen können, insbesondere zwischen Sparplanposten und Posten der verknüpften Bankkonten.
